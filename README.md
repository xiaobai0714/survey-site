# 意见反馈网站

美观简约的匿名意见收集站点，带管理员后台。普通用户**无需登录**、全部选填，直接留下意见；只有管理员登录后才能查看每一份已提交的意见（标注提交时间）。

- 用户页：`/`（首页留意见）
- 管理后台：`/admin.html`（目录表格，按意见搜索 / 导出 CSV / 退出）
- 管理员账号：`admin`　密码：`123456789`（在 `server.js` 顶部常量修改）

---

## 一、本地运行（开发 / 试用）

需要 Node.js 18+。在本目录执行：

```bash
node server.js
```

然后浏览器打开：

- 留意见：http://localhost:3000
- 管理后台：http://localhost:3000/admin.html

数据保存在 `data/submissions.json`。

---

## 二、长期部署到公网（国内轻量应用服务器，推荐）

这个网站带一个 Node 后端（负责接收意见、存数据、管理员鉴权），所以必须部署到**能运行 Node 的平台**，纯静态托管（如只传 HTML）无法保存数据。

最省事的长期方案是租一台**国内云服务器（腾讯云 / 阿里云「轻量应用服务器」，Ubuntu 22.04，约 ¥60–100/年）**，24 小时在线、固定公网 IP，本机关了也能收意见。详细步骤见 **`DEPLOY-CN.md`**。

> 仅用 `IP:端口` 访问（如 `http://公网IP:3000`）无需备案；想用自定义域名 + https 才需 ICP 备案（免费，约 1–2 周）。

---

## 三、只想快速分享“长什么样”（纯静态预览）

如果只是想发个链接让别人看看界面（**不能真正保存数据**），可以把 `public/` 目录直接传到任意静态托管（CloudStudio / GitHub Pages / Vercel 静态）。
前端会自动识别：检测不到后端时会显示「预览版」提示，不会点提交没反应。

---

## 四、常见修改点（给想自己动手的你）

| 想改的东西 | 改哪个文件 |
| --- | --- |
| 网站标题 / 副标题 / 品牌名 | `public/index.html`、`public/admin.html` |
| 意见字段（是否必填、字数上限、占位文案） | `public/index.html`（表单部分）+ `server.js`（字段与校验）+ `public/admin.html`（表格列）+ `public/js/admin.js`（导出列） |
| 配色（主色、背景、圆角） | `public/css/style.css` 顶部的 `:root` 变量 |
| 管理员账号密码 | `server.js` 顶部 `ADMIN_USER` / `ADMIN_PASS` |

> 小提示：改意见字段时记得四处同步（用户页表单 → 后端校验 → 后台表格 → 导出 CSV），否则可能存不进或显示不全。懒得同步就直接让我改。

## 五、目录结构

```
.
├── server.js            # Node 后端：接口 + 静态托管 + 数据存储
├── package.json         # 启动脚本 / Node 版本要求
├── DEPLOY-CN.md         # 国内轻量应用服务器部署说明
├── public/
│   ├── index.html       # 用户留意见页
│   ├── admin.html       # 管理员后台（登录 + 目录表格）
│   ├── css/style.css    # 样式（简约渐变风）
│   └── js/
│       ├── index.js     # 用户页逻辑（含预览版自动检测）
│       └── admin.js     # 后台逻辑（登录 / 列表 / 搜索 / 导出）
└── data/
    └── submissions.json # 意见数据（程序自动读写）
```
